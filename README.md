# Qubit AI

## 量子ビットに着想を得た、次世代のAI

Qubit AIは、**量子ビットの考え方とニューラルネットワークを組み合わせた量子インスパイアAI**です。

統計的な相関、量子状態の重ね合わせ、AIの確率的な振る舞いを、ひとつの計算モデルとして扱うことを目指しています。Qubit AIの中核には、調整可能擬似量子ビット（**APQB: Adjustable Pseudo Quantum Bit**）と、それをニューラルネットワークへ応用した**QBNN**があります。

> Qubit AIは、量子コンピュータ上で動作するAIではありません。  
> 古典コンピュータ上で、量子ビットや量子もつれから着想を得た計算構造を実装するAIです。

---

## Qubit AIのビジョン

現在のAIは、正確な回答と創造的な回答のバランスを、主にtemperatureなどの外部パラメータで調整します。

Qubit AIは、この「確定性」と「ゆらぎ」の関係を、モデル内部の状態として捉えます。

- 高い確信度：安定した、再現性の高い判断
- 高いゆらぎ：多様で、創造的な探索
- 状況に応じた調整：正確さと柔軟性の両立

Qubit AIが目指すのは、単にランダムな出力を生成することではありません。**文脈に応じて、慎重にも大胆にも振る舞えるAI**です。

## APQB：Qubit AIの基本単位

APQBは、内部角度 θ によって状態を連続的に調整する計算モデルです。

~~~text
|ψ⟩ = cosθ|0⟩ + sinθ|1⟩
~~~

APQBでは、相関 r ∈ [−1, 1] から角度 θ と補助座標 q を作ります（「APQB/QBNN 改訂版」論文（2026年10月9日）式(1)–(2)。以下、式番号は同論文、参照実装は `apqb_qbnn_v2.py`）。

~~~text
θ = ½·arccos r      (0 ≤ θ ≤ π/2)
r = cos(2θ) = ⟨Z⟩
q = sin(2θ) = √(1 − r²) = ⟨X⟩   （旧稿の T）
r² + q² = 1
~~~

r と q は単位円 r² + q² = 1 の上を連続的に動きます。q はこの状態族のコヒーレンス座標であり、AIのtemperatureそのものではありません。

| 概念 | Qubit AIでの意味 |
| :--- | :--- |
| θ | AI内部状態を調整するパラメータ |
| r | 相関（Z期待値）。確信度として使う場合は校正データとの対応を別途定義 |
| q（旧T） | コヒーレンス座標（温度そのものではない）。論文では温度を校正式 τ_AI = τ_min + (τ_max − τ_min)·q̄^γ（式(18)、参照実装 `apqb_qbnn_v2.calibrated_temperature`）で定義。現行の生成コード（`neuroquantum_layered.py`）の既定はステップ依存の正弦スケジュールで、q からは計算しない。`generate(temperature_mode="apqb")` を指定すると、最終ブロックの QBNN 層が記録した最終トークンの平均コヒーレンス η̄ = mean sech(h̃) を文脈内の分布で正規化した値 η̃ を使い、u = 1 − η̃ を同じ形の式 τ_min + (τ_max − τ_min)·u^γ に通して温度を決める。`neuroq_checkpoint.pt` では η̄ が高いほど予測エントロピーが低い（相関 −0.55）ので、モデルが迷うほど高温になる向きにしている（式(18)とは逆向き） |
| 0状態・1状態 | 二つの基本状態 |
| 重ね合わせ | 複数の可能性を保持する状態 |

### 平方根振幅座標 (n, φ, κ)

研究草稿「APQBにおける平方根振幅座標の定式化」（2026年10月17日、v0.1）は、APQB を n = 4P(1) ∈ [0, 4]、相対位相 φ、コヒーレンス係数 κ で表します。n は北極 |0⟩ からの弦距離の二乗（命題1）、r = 1 − n/2、η = √(n(4 − n))/2 は上の q と同じ量です。ρ(n, φ, κ) は任意の1量子ビット密度行列を表せます（命題2）。参照実装は `apqb_sqrt_amplitude.py`、検証は `tests/test_apqb_sqrt_amplitude.py` です。論文の範囲を超える一般ユニタリの回転則や位相緩和・振幅減衰の閉形式には、`[supplement]` と付記しています。

NeuroQuantum の `QBNNLayer` は、論文の式(11)–(12)（r = tanh s、η = sech s、dr/ds = η²）に基づいて、直近の forward の APQB 座標を記録します。

| 診断値 | 意味 |
| :--- | :--- |
| `apqb_n_mean` / `apqb_p1_mean` | s_raw = tanh(h̃) を r とみなしたときの平均 n と P(1) = n/4 |
| `apqb_eta_mean` | 平均コヒーレンス η̄ = mean sech(h̃) |
| `apqb_grad_gain` | 相関補正項の tanh 経路の勾配係数 η² の平均 |
| `apqb_saturation` | η² < 0.01（\|h̃\| ≳ 3）で勾配が 1% 未満になったユニットの割合 |

### 3次元ブロッホニューロン

`QBNNLayer`（既定 `bloch=True`、`NeuroQuantumConfig(qbnn_bloch=True, qbnn_bloch_rank=16)`）の各出力ニューロンは、z 座標 tanh(h̃) だけでなく、論文の式(6)のブロッホベクトルを持ちます。

~~~text
b_j = (κ_j η_j cos φ_j,  κ_j η_j sin φ_j,  z_j)
z_j = tanh h̃_j,  η_j = sech h̃_j,  n_j = 2(1 − z_j) = 4P(1)
φ_j, κ_j = 入力からの低ランク射影（κ = σ(·) ∈ (0, 1)）
Δ_j = (J_xᵀ s)_j x_j + (J_yᵀ s)_j y_j + (J_zᵀ s)_j z_j
~~~

‖b‖² = z² + κ²η² ≤ 1 なので、各ニューロンはつねに妥当な密度行列 ρ(n, φ, κ) に対応します（命題2）。z だけでは位相の違いによる干渉を区別できません（式(9)）。この位相情報を x, y 成分が運びます。J_z は従来の J です。J_x, J_y は低ランクで、ゼロから学習を始めます。そのため、1次元版のチェックポイントを読み込むと出力は1次元版と完全に一致します（欠けたパラメータは読み込み時に補われます）。追加されるパラメータは約2%です（`neuroq_checkpoint.pt` の構成で +1.05M）。

### 測定サンプリング

n = 4P(1)（論文の式(2)）を使い、QBNN の各ニューロンを計算基底で「測定」できます。測定したニューロンの z は期待値 1 − n/2 の代わりに、確率 P(1) = n/4 で −1、それ以外で +1 になります。E[測定値] = z なので平均は変わりません。測定したニューロンは位相とコヒーレンスを失います（x = y = 0）。既定では無効です。

~~~python
ai.generate(prompt, measurement_rate=0.5)          # 半分のニューロンを測定して多様性を加える
with ai.model.measurement(1.0):                    # 任意の forward で測定を有効にする
    logits = ai.model(tokens)
ai.measurement_uncertainty(prompt, shots=8)        # 測定ごとに貪欲生成し、答えの割れ方で迷いを測る
~~~

`measurement_uncertainty` は MC ドロップアウトと同じ考え方の不確かさ推定です。返り値は、回答の一致率（`answer_agreement`）、回答どうしの類似度（`answer_similarity`）、次トークンの相互情報量（`next_token.mutual_information`）です。`neuroq_checkpoint.pt` で6問を試すと、覚えている定型回答（「あなたは誰ですか？」など）では8回すべて同じ回答になり、提案や列挙を求める質問では一致率が 25〜50% に下がりました。ただし、割れることは誤りを意味しません（正しく答えた「日本の首都」も 50%）。次トークン1つだけの指標は、ほとんど差が出ませんでした。

### ガウス記号による n の整数化

`generate(n_floor=True)` または `with ai.model.n_floor():` で、各 QBNN ニューロンの n をガウス記号で ⌊n⌋ ∈ {0, 1, 2, 3, 4} に切り捨てます。z = 1 − ⌊n⌋/2 ∈ {1, ½, 0, −½, −1}、η = √(⌊n⌋(4 − ⌊n⌋))/2 となり、z² + η² = 1 なのでブロッホベクトルは球の内側に残ります。勾配は straight-through で連続値のものを流します。n は (0, 4) を動くので ⌊n⌋ = 4 は飽和時にしか現れず、切り捨てで n は平均約 0.5 小さくなります。`neuroq_checkpoint.pt` では ⌊n⌋ = 0, 1, 2, 3 がそれぞれ 19%, 30%, 31%, 21% で、予測の変化はごく小さい値でした（1位の予測の一致 98.3%）。

`NeuroQuantum.get_quantum_info()` はブロックごとにこれらを返します（3次元ニューロンでは κ の平均 `bloch_kappa_mean`、‖b‖ の平均 `bloch_norm_mean`、純度 (1 + ‖b‖²)/2 の平均 `bloch_purity_mean` も返します）。学習の終わりと対話モードの `/quantum` コマンドでも表示されます。どの値もチェックポイントには保存されません。

### 完全ブロッホ球と完全QBNN

**完全ブロッホ球**は、二葉双曲面と2つの半球体の組です。

- 二葉双曲面 ζ² − u² − v² = 1 の上の葉は、射影 P(q) = (u, v, 1)/ζ で北半球（|0⟩ 側）に移ります。下の葉は南半球（|1⟩ 側）に移ります。
- 偏極 m = tanh c を掛けた b = m·P(q) は、2つの半球体でブロッホ球体全体を覆います。
- 葉軸で測定すると、状態はどちらかの葉に収縮します。

完全QBNN は、このニューロンだけで隠れ層を作ったネットワークです。分類器 `CompleteQBNN` と、再帰型の文字言語モデル `CompleteQBNNLM` / `CompleteQBNNAI` があります。実装は `complete_qbnn.py`、検証は `tests/test_complete_qbnn.py`、詳細は [COMPLETE_QBNN.md](COMPLETE_QBNN.md) にあります。

## QBNN：APQBを利用したニューラルネットワーク

QBNN（APQB Neural Network）は、通常のアフィン経路に APQB の相関ゲートを掛け合わせる、検証可能な古典ニューラルネットワークです（式(13)–(14)、参照実装 `apqb_qbnn_v2.QBNNLayerV2`）。

~~~text
u = W h + b                         （通常の線形変換）
a = P h + c,  r = tanh a,  q = sech a   （APQB座標, r² + q² = 1）
c_r = J_rᵀ r,  c_q = J_qᵀ q
g = 1 + λ_r c_r + λ_q c_q           （相関ゲート）
h′ = σ(u ⊙ g)
~~~

1. **古典的な線形結合**：重み行列 W によって情報を伝達します。
2. **相関ゲート**：APQB 座標 (r, q) を学習可能な行列 J で混ぜ、出力を要素ごとに調整します。J は学習可能な古典的相互作用であり、物理的な量子もつれを実現する演算子ではありません。

J = 0 または λ = 0 のとき、出力は通常の層 σ(Wh + b) と厳密に一致します（命題4）。初期化では J = 0、λ を小さな非ゼロ値にするため、学習開始時は通常の層と同じ出力から相関経路の学習が始まります。層間に加算型の補正を加える旧稿の設計は比較用の設計候補です。なお、現行の生成モデル（`neuroquantum_layered.py` の `QBNNLayer`）と `qbnn_layered.py` は、この加算型の設計を使っています。

## 数学的な考え方

活性化を持たない全結合層はアフィン変換の合成であり、高次の交互作用項が自動的に現れるわけではありません。APQBとニューラルネットワークの対応は、次の限定された範囲で扱います（同論文 第4章）。

~~~text
ブール入力 x ∈ {−1,+1}ᵈ：
f(x) = Σ_{S⊆{1..d}} f̂(S) ∏_{i∈S} xᵢ      （2ᵈ 個の直交基底で一意に展開, 式(10)）

独立な APQB 座標 zᵢ = rᵢ + i qᵢ の部分集合積：
Φ_S(z) = ∏_{i∈S} zᵢ                       （rᵢ = xᵢ, qᵢ = 0 で上の基底と一致, 式(12)）
~~~

一変数の F = Σ_k A_k zᵏ（z = e^(i2θ)）は次数 K で K+1 個の係数しか持たず、n 変数の 2ⁿ 個の係数とは同一視しません。一般のニューラルネットワークとの同型性も主張しません。

この限定された対応を利用し、ニューラルネットワークの特徴表現に、相関・重ね合わせ・ゆらぎという量子インスパイアの視点を導入します。

## TypeSafe AI Jevによる判断レイヤー

Qubit AIは、TypeSafe AIのJevをチャット生成モデルとしてではなく、回答評価・再試行判断・エージェント分岐を行う型付き判断レイヤーとして利用できます。

### サーバー設定

RunPodワーカーの環境変数に次を設定します。

~~~bash
TYPESAFE_JEV_URL=https://<your-typesafe-endpoint>
TYPESAFE_API_KEY=<your-typesafe-api-key>
TYPESAFE_JEV_MODEL=jev
TYPESAFE_JEV_TIMEOUT=20
~~~

APIキーはクライアントへ渡さず、RunPodワーカー側だけに設定してください。

### RunPodリクエスト

~~~json
{
  "input": {
    "action": "jev_judge",
    "prompt": "ユーザーの質問に対するQubit AIの回答です。",
    "parameters": {
      "labels": ["answer", "needs_retry", "needs_tool"],
      "instruction": "この回答が質問に適切か判断してください。"
    }
  }
}
~~~

返却値はJevの判断結果を `decision` に格納します。Qubit AIの生成処理と分離しているため、Jevが未設定でも通常の推論は動作します。TypeSafe AIの実際のAPI URLとレスポンス形式に合わせて、`TYPESAFE_JEV_URL`を設定してください。
